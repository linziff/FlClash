# Windows Bug 与优化清单

以下为 Windows 端待处理问题，修复后请将状态更新为“已修复”；完成构建和实际运行验证后再标记为“已验证”。

## 待处理问题

### 1. 任务栏与隐藏图标栏 Logo
- [ ] 优化 Windows 任务栏应用 Logo，确保清晰、比例正确、透明边缘无异常。
- [ ] 优化系统托盘/隐藏图标栏 Logo，确保图标清晰且与应用品牌一致。
- [ ] 托盘图标应根据运行状态正确切换：停止（灰色）、正常运行（绿色）、TUN（蓝色）、安全模式（橙色）。
- [ ] 检查不同 DPI、浅色/深色任务栏下的显示效果。

### 2. 登录、注册与忘记密码
- [ ] 登录页输入框补齐对应图标。
- [ ] 注册页输入框补齐对应图标。
- [ ] 修复注册邮箱后缀选择器，选择后缀后，输入框显示、验证码发送和注册请求必须使用同一个完整邮箱地址。
- [ ] 忘记密码页输入框补齐对应图标。

### 3. 公告
- [ ] 公告界面补齐缺失图标，统一图标风格、尺寸和对齐方式。

### 4. 商店
- [ ] 每个套餐名称前添加对应独立图标。
- [ ] 套餐流量、设备数、速度等介绍标签补齐对应图标。
- [ ] 购买周期选项补齐图标。
- [ ] 支付方式选项补齐图标。
- [ ] 检查图标与文字的间距、垂直居中及 Windows 字体清晰度。

### 5. 客服界面
- [ ] 移除客服界面顶部当前特殊效果。
- [ ] 顶部恢复为与应用其他页面一致的常规界面效果，统一背景、边距和层级。

### 6. 我的页面灰屏
- [ ] 排查并修复“我的”页面灰屏问题。
- [ ] 检查页面初始化、用户信息/套餐数据加载、异步状态和异常兜底。
- [ ] 验证登录前、登录后、数据为空及请求失败等场景。
